# Profile assets and updates

## Hero photo

The public GitHub profile uses `assets/hero-public.png`: a **wide, cropped version** of the original Flutter banner, ending above its phone-number/contact block while preserving the original branding and portrait.

To regenerate it on Windows (Node.js required, no dependencies):

```powershell
npm run assets:crop
```

The source is `assets/ChatGPT Image Oct 19, 2026, 03_26_25 AM-2.png`.
The side portrait remains `assets/ChatGPT Image Oct 19, 2026, 03_26_24 AM-1.png`.

**Privacy note:** The original source banner still exists within this public repository (including previous Git commits); cropping it in the README only removes the displayed phone number. For complete removal from Git history, history rewriting and cache behavior must be considered separately and explicitly authorized.

## Other assets

- `assets/hero.svg` and `assets/profile-card.svg` are original vector alternatives.
- Typing animation, language stats and streak cards load from public external SVG services.
- The broken external activity graph was removed; the README links to GitHub's native contribution view instead.
- Contribution snake is generated by `.github/workflows/snake.yml` on push, schedule or manual dispatch and published to the `output` branch.

## GitHub profile pins

Pinned repositories are **account-level profile settings**, not README data. On your GitHub profile choose **Customize your pins** and select your strongest current public repositories, such as `amomy_bus`, `brixel`, and `Personal-Website`.
