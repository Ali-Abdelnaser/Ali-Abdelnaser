- `assets/hero.svg`
- `assets/profile-card.svg`

The typing effect, statistics, streak and activity graph are hosted SVG widgets. They may occasionally be rate-limited.

The contribution snake is generated by `.github/workflows/snake.yml`; it runs on main pushes, on a schedule, and via manual GitHub Actions dispatch. It publishes the generated SVGs on the `output` branch. If an Actions push is rejected, review Settings > Actions > General > Workflow permissions.
